# Figuras

Esta carpeta reúne las visualizaciones elaboradas para el proyecto de análisis y visualización de datos espaciales basado en datos de NEON.

Aquí se almacenarán mapas, gráficos y otras figuras generadas durante el desarrollo del proyecto en RStudio.

Las figuras se elaboran a partir de datos obtenidos desde NEON y tienen fines exclusivamente académicos y didácticos.

Se incorporarán nuevas visualizaciones a medida que avance el análisis.
