# Origen de los datos

Los datos utilizados en este repositorio fueron obtenidos de
**NEON (National Ecological Observatory Network)**, una plataforma
de acceso abierto que proporciona información ecológica para
la investigación científica.

Estos datos fueron utilizados como material de referencia para
el desarrollo de actividades académicas relacionadas con el
análisis y visualización de datos espaciales mediante RStudio.

**Fuente:** National Ecological Observatory Network (NEON).

**Origen:** Datos ecológicos descargados del portal oficial de NEON.

**Uso:** Aprendizaje de análisis y visualización de datos
espaciales en RStudio.

**Reconocimiento de autoría:** Los datos originales fueron
recopilados y publicados por NEON. Los análisis y visualizaciones
desarrollados en este repositorio corresponden a un ejercicio
académico y no implican autoría sobre los datos originales.
