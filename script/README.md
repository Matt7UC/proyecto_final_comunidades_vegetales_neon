# Scripts

Esta carpeta contiene los scripts desarrollados en **RStudio** para el procesamiento, análisis exploratorio y visualización de datos ecológicos obtenidos del **National Ecological Observatory Network (NEON)**.

Los códigos permiten explorar variables relacionadas con la composición florística, riqueza de especies, cobertura vegetal y distribución espacial.

Los procedimientos desarrollados tienen fines académicos y servirán como referencia metodológica para futuros análisis de mi tesis de magíster.

Se incorporarán nuevos scripts conforme avance el proyecto.
